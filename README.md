# Alzheimer’s MRI Data Engineering Pipeline

## Overview
This project builds a production-grade, metadata-aware MRI data engineering pipeline
designed for Alzheimer’s disease research.

The focus is on:
- Safe ingestion of brain MRI scans
- Metadata integrity and consistency
- Longitudinal subject-level organization
- Leakage-safe dataset construction
- Reproducible, auditable ML-ready outputs

This project prioritizes **data trustworthiness and longitudinal consistency**
over model accuracy.
